# Archived working notes

These files are historical working notes kept for reference. They are not instructions and do not describe the current code.

- `plans/`: step-by-step implementation plans written before or during each change (October 2026). Their checkboxes were never updated, so unchecked items are not a backlog, and some details were superseded during review. For example, the route `maxDuration` values in the timeouts plan differ from the route files.
- `specs/`: the design note for the App Store sign-in handoff.

For current behaviour, read [ARCHITECTURE.md](../../ARCHITECTURE.md), the [ADR index](../adr/README.md) and the code. New plan files are not added to the repository; see the [documentation index](../README.md).
